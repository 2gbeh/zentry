## Setup

```sh
git clone https://github.com/hwp-labs/zentry.git
cd zentry

pnpm install
pnpm run dev

# Local:  http://localhost:3000
# Live:   https://zentry.vercel.app
```

## Firebase

**Build**
- **Authentication:** User sign-in with email, phone, and social providers.
- **Cloud Firestore:** Scalable NoSQL document database with realtime sync.
- **Realtime Database:** Original JSON-tree database with low-latency sync.
- **Data Connect:** Managed PostgreSQL (Cloud SQL) with typed queries and generated SDKs.
- **Cloud Storage:** File storage for images, video, and user uploads.
- **Cloud Functions:** Serverless backend code triggered by events or HTTP.
- **Hosting:** Fast static and dynamic web hosting with a CDN.
- **App Hosting:** Git-based hosting for full-stack frameworks like Next.js and Angular.
- **Extensions:** Prebuilt backend features you install with a few clicks.
- **App Check:** Blocks abuse by verifying requests come from your genuine app.
- **Firebase AI Logic:** Call Gemini and other generative models directly from your app.
- **Genkit:** Open-source framework for building AI-powered features.
- **ML Kit:** On-device machine learning for mobile apps.

**Release and monitor**
- **Crashlytics:** Real-time crash reporting.
- **Performance Monitoring:** App startup, network, and screen rendering metrics.
- **Test Lab:** Run tests on real and virtual devices in the cloud.
- **App Distribution:** Send pre-release builds to testers.

**Engage and optimize**
- **Google Analytics:** Free, unlimited event and audience analytics.
- **Cloud Messaging (FCM):** Push notifications and messaging across platforms.
- **In-App Messaging:** Targeted contextual messages inside your app.
- **Remote Config:** Change app behavior and appearance without a new release.
- **A/B Testing:** Experiment with UI, features, and messaging.

**Developer tools**
- **Firebase CLI:** Deploy and manage projects from the terminal.
- **Emulator Suite:** Run Firebase services locally for development and testing.
- **Firebase Studio:** Browser-based, AI-assisted workspace for building apps.
- **Firebase Console:** Web dashboard to manage everything.
- **Firebase Admin SDK:** Privileged server-side access from Node, Python, Java, Go, and C#.

**Retired**
- **Dynamic Links:** Shut down in August 2025.
- **Predictions:** Deprecated.
